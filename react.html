🧠 O que é React?

React é uma biblioteca JavaScript utilizada para criar interfaces.

Em vez de criar uma página inteira dentro de um único arquivo HTML, podemos dividir a interface em pequenas partes chamadas componentes. 

Home
↓
Header
↓
Categorias
↓
Footer

No React, podemos representar essas partes assim: 

App
│
├── Header
│
├── Categorias
│   │
│   ├── CategoryCard
│   ├── CategoryCard
│   ├── CategoryCard
│   └── CategoryCard
│
└── Footer

🚀 Criando um projeto React

Vamos utilizar o Vite para criar e executar o projeto.

1️⃣ Criar o projeto

npm create vite@latest

O terminal fará algumas perguntas.

2️⃣ Nome do projeto

Project name:
howto

3️⃣ Escolher framework

React

4️⃣ Escolher linguagem

JavaScript

5️⃣ Entrar na pasta

cd howto

6️⃣ Instalar dependências

npm install

7️⃣ Iniciar o projeto

npm run dev

O terminal mostrará algo parecido com: 

Local: http://localhost:5173/

Abra o endereço no navegador.

⚛️ O que é JSX?

JSX permite escrever uma estrutura parecida com HTML dentro do JavaScript.

HTML

<h1>Olá!</h1>

JSX

<h1>Olá!</h1>

Visualmente eles podem ser muito parecidos.

⚠️ class

No HTML: 

<div class="categoria">

No React: 

<div className="categoria">

🧠 Regra

HTML
↓
class

React / JSX
↓
className

⚠️ Elementos

Elementos que não possuem conteúdo devem ser fechados.

⚠️ JavaScript no JSX

Para colocar JavaScript dentro do JSX, usamos: 

{ }

Exemplo: 

const nome = 'Wagner'

<h1>
    Olá {nome}
</h1>

Podemos pensar no <CategoryCard /> como uma chamada ao componente.

O problema

<CategoryCard />
<CategoryCard />
<CategoryCard />

Todos os cards seriam iguais.

Precisamos enviar informações diferentes para cada card.

É aqui que entram as:

📦 Props

📦 O que são Props?

Props são informações enviadas de um componente para outro.

Neste caso, o App.jsx envia informações para o CategoryCard.jsx.

📤 Enviando Props

As Props são enviadas através dos atributos do componente: 

<CategoryCard

    icone="⚡"

    titulo="JavaScript"

    descricao="Interações, eventos, fetch e lógica."

    link="js.html"

/>

🧠 Fluxo

App.jsx
   ↓
envia Props
   ↓
CategoryCard.jsx
   ↓
recebe Props

📦 Informações enviadas

icone
titulo
descricao
link

Por exemplo: 

titulo="JavaScript"

significa que o valor JavaScript está sendo enviado para o componente.

📤 Enviando no App.jsx

O componente pai envia as Props. Neste caso, o componente pai é o App.jsx. 

import CategoryCard from './components/CategoryCard'


function App() {

    return (

        <>

            <CategoryCard

                icone="⚡"

                titulo="JavaScript"

                descricao="Interações, eventos, fetch e lógica."

                link="js.html"

            />

        </>

    )

}


export default App

📥 Recebendo Props

O componente filho recebe as informações através do parâmetro props. 

function CategoryCard(props) {

    return (

        <a
            href={props.link}
            className="categoria"
        >

            <div className="icone">

                {props.icone}

            </div>


            <div className="categoria-info">

                <h2>

                    {props.titulo}

                </h2>


                <p>

                    {props.descricao}

                </p>

            </div>

        </a>

    )

}

export default CategoryCard

🧠 Entendendo o props

O props funciona como um pacote contendo as informações enviadas pelo componente pai. 

props
│
├── props.icone
├── props.titulo
├── props.descricao
└── props.link

Se o App.jsx enviar: 

titulo="JavaScript"

o CategoryCard poderá acessar: 

props.titulo

E o resultado será: 

JavaScript

⚡ Desestruturação

Podemos receber diretamente as propriedades, sem precisar escrever props. todas as vezes. 

function CategoryCard({

    icone,
    titulo,
    descricao,
    link

})

Agora podemos usar diretamente: 

{icone}

{titulo}

{descricao}

{link}

Isso é apenas uma forma mais curta de acessar as Props.

🧩 Componente completo

function CategoryCard({

    icone,
    titulo,
    descricao,
    link

    return (

        <a

                <h2>

                    {titulo}

                </h2>


                <p>

                    {descricao}

                </p>

            </div>

        </a>

    )

}

export default CategoryCard

🏠 Aplicando na Home

📥 Imports

import Header
    from './components/Header'

import CategoryCard
    from './components/CategoryCard'

import Footer
    from './components/Footer'

import categories
    from './data/categories'

🧩 App.jsx

function App() {

    return (

        <>

            <Header />


            <main>

                <section className="inicio">


                    <h1>

                        Como eu faço isso mesmo?

                    </h1>


                    <p
                        className="subtitulo"
                    >

                        Escolha uma categoria
                        para encontrar
                        meus tutoriais.

                    </p>


                    <div
                        className="categorias"
                    >

                        {categories.map(
                            (category) => (

                                <CategoryCard

                                    key={category.title}

                                    icone={category.icon}

                                    titulo={category.title}

                                    descricao={
                                        category.description
                                    }

                                    link={category.link}

                                />

                            )
                        )}

                    </div>


                </section>

            </main>


            <Footer />


        </>

    )

}

export default App
