🧩 Funções

Uma função é um bloco de código que podemos executar quando necessário.

🔹 Função tradicional

function salvar() {

            console.log('Salvando...');
            

            }

Para executar: 

salvar();

📥 Função com parâmetro

function saudacao(nome) {

            console.log('Olá, ' + nome);
            

            }
saudacao('Wagner');

↩️ Return

function somar(a, b) {

            return a + b;
            

            }

            const resultado = somar(10, 5);

            console.log(resultado);

O return devolve um valor para quem chamou a função.

⚡ Arrow Function

Arrow Function é uma forma mais curta de escrever funções.

A mesma função tradicional: 

function somar(a, b) {

            return a + b;
            

            }

Pode ser escrita como: 

const somar = (a, b) => {

            return a + b;
            

            };

🧠 Como ler

const somar = (a, b) => {
                        ↑
                    parâmetros

                        =>
                        "vai para"

                            {
                            código
                            }

⚡ Arrow Function curta

Quando a função possui apenas uma expressão que será retornada, podemos simplificá-la ainda mais. 

const somar = (a, b) => a + b;

Isso equivale a: 

const somar = (a, b) => {

            return a + b;
            

            };

👤 Apenas um parâmetro

Quando existe apenas um parâmetro, os parênteses podem ser omitidos. 

const dobrar = numero => numero * 2;

Também podemos escrever: 

const dobrar = (numero) => numero * 2;

As duas formas são válidas.

🛠️ Arrow Function com bloco

const verificar = (status) => {

            if (status === 'Concluído') {

                console.log('Tudo certo!');

            } else {

                console.log('Ainda pendente.');

            }
            

            };

📌 Onde vamos usar no GatMan?

Arrow Functions aparecem bastante quando trabalhamos com eventos, respostas do fetch() e métodos de arrays. 

botao.addEventListener('click', () => {

            console.log('Clicou!');
            

            });

Portanto, vale muito a pena entender Arrow Functions antes de avançarmos para os eventos.

📚 Arrays e métodos úteis

Arrays são estruturas usadas para guardar vários valores dentro de uma única variável. 

const nomes = [
            'João',
            'Maria',
            'Carlos'
            

            ];

O JavaScript possui vários métodos para trabalhar com esses valores. Alguns dos mais importantes são forEach(), map(), filter() e find().

🔁 forEach()

Executa uma função para cada item do array. 

const nomes = ['João', 'Maria', 'Carlos'];
            

            nomes.forEach((nome) => {

            
            console.log(nome);
            

            });

Resultado: 

João
            

            Maria
            Carlos

O forEach() é muito útil quando queremos simplesmente executar alguma ação para cada elemento.

⚠️ Importante

O forEach() não é utilizado para criar um novo array com os resultados.

🗺️ map()

O map() percorre o array e cria um novo array com o resultado da transformação de cada item. 

const numeros = [1, 2, 3, 4];
            

            const dobrados = numeros.map((numero) => {

            
            return numero * 2;
            

            });

            console.log(dobrados);

Resultado: 

[2, 4, 6, 8]

🧠 Como pensar no map()

1 → 2
            

            2 → 4
            3 → 6
            4 → 8

            Cada item
            ↓
            é transformado
            ↓
            novo array

⚡ Forma curta

const dobrados = numeros.map(numero => numero * 2);

Aqui temos novamente uma Arrow Function.

🔎 filter()

O filter() cria um novo array contendo somente os elementos que atendem a uma condição. 

const numeros = [1, 2, 3, 4, 5, 6];
            

            const pares = numeros.filter((numero) => {

            
            return numero % 2 === 0;
            

            });

            console.log(pares);

Resultado: 

[2, 4, 6]

🧠 Como pensar no filter()

1 → ❌
            

            2 → ✅
            3 → ❌
            4 → ✅
            5 → ❌
            6 → ✅

            Somente os que passam
            na condição
            ↓
            novo array

🏨 Exemplo parecido com o GatMan

const inspeções = [

            { status: 'Pendente' },
            { status: 'Concluído' },
            { status: 'Pendente' }
            

            ];

            const pendentes = inspeções.filter((inspecao) => {

Agora pendentes contém somente as inspeções cujo status é Pendente.

🎯 find()

O find() procura um elemento que atenda a uma condição e retorna o primeiro encontrado. 

const nomes = ['João', 'Maria', 'Carlos'];
            

            const resultado = nomes.find((nome) => {

            
            return nome === 'Maria';
            

            });

            console.log(resultado);

Resultado: 

Maria

🧠 Diferença entre find() e filter()

find()
            

            ↓
            encontra UM elemento

            filter()
            ↓
            encontra VÁRIOS elementos

❓ some()

Verifica se pelo menos um elemento atende à condição.

O resultado é true ou false. 

const numeros = [1, 3, 5, 8];
            

            const existePar = numeros.some((numero) => {

            
            return numero % 2 === 0;
            

            });

            console.log(existePar);
true

Existe pelo menos um número par: 8.

✅ every()

Verifica se todos os elementos atendem à condição. 

const numeros = [2, 4, 6, 8];
            

            const todosPares = numeros.every((numero) => {

            
            return numero % 2 === 0;
            

            });

            console.log(todosPares);
true

🔍 includes()

const setores = [

⚠️ Erro comum

Um erro bastante comum é usar map() quando queremos apenas executar uma ação.

Por exemplo: 

nomes.map((nome) => {

            console.log(nome);
            

            });

Se não precisamos do novo array, o mais apropriado é: 

nomes.forEach((nome) => {

            console.log(nome);
            

            });

Outra confusão comum é usar filter() esperando receber um único objeto. O filter() sempre retorna um array, mesmo que encontre apenas um elemento. 

const resultado = lista.filter(...);
            

            console.log(resultado);
            // → array

Se queremos apenas o primeiro resultado, normalmente usamos find().

🏨 Exemplo completo

const inspeções = [

            {
                item: 'Extintor',
                status: 'Pendente'
            },

            {
                item: 'Alarme',
                status: 'Concluído'
            },

            {
                item: 'Porta corta-fogo',
                status: 'Pendente'
            }
            

            ];

            const pendentes = inspeções.filter((inspecao) => {

            
            return inspecao.status === 'Pendente';
            

            });

            const nomes = pendentes.map((inspecao) => {

            
            return inspecao.item;
            

            });

            console.log(nomes);

Primeiro usamos filter() para selecionar somente as inspeções pendentes.

Depois usamos map() para transformar essas inspeções em apenas seus nomes. 

[
            'Extintor',
            'Porta corta-fogo'
            

            ]

Essa combinação de métodos é muito comum em JavaScript.

🎯 Selecionando elementos HTML

Para o JavaScript interagir com um elemento HTML, primeiro precisamos encontrá-lo.

Existem várias formas de fazer isso. No código moderno, querySelector() e querySelectorAll() são especialmente úteis porque utilizam seletores CSS.

🎯 querySelector()

Seleciona o primeiro elemento que corresponde ao seletor informado. 

const botao = document.querySelector('#salvar');

Se temos: 

<button id="salvar">Salvar</button>

O JavaScript encontra esse botão através do seu id.

🔵 ID

document.querySelector('#salvar');

O # indica que estamos procurando um id.

🟢 Classe

document.querySelector('.botao-salvar');

O . indica uma classe. 

<button class="botao-salvar">
            Salvar

🏷️ Tag

document.querySelector('button');

Também podemos procurar diretamente pelo nome da tag.

Porém, como querySelector() retorna apenas o primeiro resultado, se houver vários botões ele pegará somente o primeiro.

🎯 Seletores mais específicos

Como querySelector() utiliza seletores CSS, podemos combinar seletores. 

document.querySelector('#formulario .botao-salvar');

Nesse caso estamos procurando um elemento com a classe botao-salvar que esteja dentro do elemento com o ID formulario.

📚 querySelectorAll()

Enquanto querySelector() pega o primeiro elemento, querySelectorAll() pega todos os elementos correspondentes. 

const botoes = document.querySelectorAll('.botao');

Se existirem vários elementos: 

<button class="botao">Salvar</button>

O JavaScript terá uma coleção contendo os três elementos.

🔁 Percorrendo vários elementos

const botoes = document.querySelectorAll('.botao');


            botoes.forEach((botao) => {


            console.log(botao);


            });

Aqui aparece novamente uma Arrow Function: 

(botao) => {

            console.log(botao);


            }

O forEach() executa a função uma vez para cada elemento encontrado.

🆔 getElementById()

Existe também uma forma específica para buscar elementos pelo ID: 

const botao = document.getElementById('salvar');

Nesse caso não usamos #.

Isso: 

document.getElementById('salvar');

equivale, na prática, a: 

document.querySelector('#salvar');

⚡ Guia rápido

Primeiro elemento:


            document.querySelector('#id');

            Todos os elementos:

            document.querySelectorAll('.classe');

            Pelo ID:

            document.getElementById('id');

            Classe:

            document.querySelector('.classe');

            Tag:

            document.querySelector('button');

            getElementById()
            ↓

🖱️ Eventos e addEventListener()

Um evento é uma ação que acontece na página. Por exemplo: clicar em um botão, enviar um formulário, alterar um campo, passar o mouse ou pressionar uma tecla.

O JavaScript pode "escutar" esses eventos e executar alguma ação quando eles acontecerem.

👂 addEventListener()

elemento.addEventListener('evento', funcao);

Podemos interpretar assim: 

elemento
            ↓
            

            quem vamos observar

            'evento'
            ↓
            o que estamos esperando acontecer

            funcao
            ↓
            o que devemos fazer quando acontecer

🖱️ Exemplo com clique

HTML: 

<button id="salvar">Salvar</button>

JavaScript: 

const botao = document.querySelector('#salvar');
            

            botao.addEventListener('click', () => {

            
            console.log('O botão foi clicado!');
            

            });

Nesse exemplo, o JavaScript encontra o botão e fica esperando o evento click.

Quando o usuário clicar, a Arrow Function será executada.

⚡ Forma de pensar

Quando
            ↓
            

            o botão receber um
            ↓
            click
            ↓
            faça isso

🧩 Função separada

A função não precisa necessariamente ficar diretamente dentro do addEventListener(). 

function salvar() {

            console.log('Salvando...');
            

            }

            const botao = document.querySelector('#salvar');

            botao.addEventListener('click', salvar);

Aqui passamos a função sem colocar () depois do nome. 

botao.addEventListener('click', salvar);

Não fazemos: 

botao.addEventListener('click', salvar());

Porque salvar() executaria a função imediatamente, em vez de esperar o clique.

📝 Evento de formulário — submit

Para formulários, um dos eventos mais importantes é submit. 

const formulario = document.querySelector('#formulario');
            

            formulario.addEventListener('submit', (event) => {

            
            event.preventDefault();

            console.log('Formulário enviado!');
            

            });

🛑 preventDefault()

event.preventDefault();

Impede o comportamento padrão daquele evento.

Em um formulário HTML, o comportamento padrão normalmente envolve o navegador enviar o formulário e recarregar ou navegar para outra página.

No GatMan, podemos impedir esse comportamento para que o JavaScript possa enviar os dados usando fetch().

📦 O objeto event

formulario.addEventListener('submit', (event) => {

            console.log(event);
            

            });

O parâmetro event contém informações sobre o evento que aconteceu.

Podemos dar outro nome para ele: 

formulario.addEventListener('submit', (e) => {

            e.preventDefault();
            

            });

event e e são apenas nomes de variáveis. O nome não muda o funcionamento.

⌨️ Outros eventos comuns

click

            ↓

            change

            input
            ↓

            focus
            ↓

            blur
            ↓
            elemento perdeu foco

            ↓

            ↓

            mouseleave
            ↓

🎯 Exemplo com input

const campo = document.querySelector('#nome');
            

            campo.addEventListener('input', (event) => {

            
            console.log(event.target.value);
            

            });

event.target representa o elemento que disparou o evento.

Portanto: 

event.target.value

significa o valor atual daquele campo.

🔘 Vários botões

const botoes = document.querySelectorAll('.botao');
            

            botoes.forEach((botao) => {

            
            botao.addEventListener('click', () => {

                console.log('Botão clicado!');

            });
            

            });

Aqui juntamos três conceitos que já aprendemos: 

querySelectorAll()
                ↓
            

            encontra vários elementos

            forEach()
            ↓
            percorre os elementos

            addEventListener()
            ↓
            escuta o evento de cada elemento

💾 O padrão que usaremos no GatMan

const formulario = document.querySelector('#formulario');
            

            formulario.addEventListener('submit', (event) => {

            
            event.preventDefault();

            // pegar dados

            // enviar para PHP

            // receber resposta

            // atualizar a página
            

            });

Esse padrão será a base para os formulários que conversam com os arquivos PHP do GatMan.

🖥️ Manipulando o HTML (DOM)

DOM significa Document Object Model. É a representação da página HTML que o JavaScript consegue acessar e modificar.

Em termos simples: 

HTML
            

            ↓
            DOM
            ↓
            JavaScript
            ↓
            altera a página

🎯 Selecionar um elemento

const titulo = document.querySelector('#titulo');

Depois de guardar o elemento em uma variável, podemos trabalhar com ele.

📝 textContent

textContent permite ler ou alterar o texto de um elemento. 

const titulo = document.querySelector('#titulo');
            

            titulo.textContent = 'Novo título';

HTML: 

<h2 id="titulo">Título antigo</h2>

Depois do JavaScript: 

<h2 id="titulo">Novo título</h2>

📖 innerHTML

innerHTML permite alterar o conteúdo HTML que está dentro de um elemento. 

const mensagem = document.querySelector('#mensagem');
            

            mensagem.innerHTML = 'Salvo com sucesso!';

A diferença principal: 

textContent
            

            ↓
            trata como texto

            innerHTML
            ↓
            interpreta HTML

⚠️ Cuidado com innerHTML

Evite colocar diretamente no innerHTML conteúdo que veio de usuários ou de fontes não confiáveis. Para simplesmente alterar texto, prefira textContent.

📥 value

Para campos de formulário, usamos principalmente value para acessar ou alterar o valor. 

const nome = document.querySelector('#nome');
            

            console.log(nome.value);

Para alterar: 

nome.value = 'Wagner';

Exemplo: 

<input
            type="text"
            id="nome"
            

            >

🧹 Limpando um formulário

Podemos limpar um campo individual: 

campo.value = '';

Ou podemos limpar o formulário inteiro usando reset(). 

formulario.reset();

Isso é muito útil depois que um cadastro foi salvo com sucesso.

👁️ Mostrar e esconder elementos

Podemos acessar o estilo de um elemento através de style. 

const mensagem = document.querySelector('#mensagem');
            

            mensagem.style.display = 'none';

Para mostrar novamente: 

mensagem.style.display = 'block';

⚠️ Mas existe uma forma melhor

Em projetos maiores, normalmente é melhor controlar a aparência através de classes CSS em vez de colocar estilos diretamente no JavaScript.

🎨 classList

classList permite adicionar, remover e verificar classes CSS.

Adicionar classe

elemento.classList.add('ativo');

Remover classe

elemento.classList.remove('ativo');

Alternar classe

elemento.classList.toggle('ativo');

O toggle() adiciona a classe se ela não existir e remove se ela já existir.

Verificar classe

elemento.classList.contains('ativo');

Retorna true ou false.

🔗 Atributos

Podemos ler ou alterar atributos HTML usando getAttribute() e setAttribute().

Ler atributo

const imagem = document.querySelector('#foto');
            

            const caminho = imagem.getAttribute('src');

Alterar atributo

imagem.setAttribute('src', 'nova-foto.jpg');

🆕 Criar elementos

O JavaScript também pode criar novos elementos HTML. 

const novoParagrafo = document.createElement('p');
            

            novoParagrafo.textContent = 'Novo texto';

Criar o elemento não significa que ele já apareceu na página. Precisamos adicioná-lo ao DOM. 

document.body.appendChild(novoParagrafo);

➕ append()

Podemos adicionar conteúdo dentro de um elemento utilizando append(). 

const lista = document.querySelector('#lista');
            

            const item = document.createElement('li');

            item.textContent = 'Novo item';

            lista.append(item);

🗑️ Remover elemento

Um elemento pode ser removido usando remove(). 

const mensagem = document.querySelector('#mensagem');
            

            mensagem.remove();

🧠 Exemplo prático

Imagine que temos uma mensagem de sucesso: 

<div id="mensagem" class="mensagem"></div>

📤 Enviando dados para o PHP

Depois de aprender a encontrar elementos e reagir aos eventos, podemos fazer o JavaScript conversar com o PHP.

No GatMan, um dos principais mecanismos para isso é o fetch().

🌐 O que é fetch()?

fetch() permite fazer uma requisição HTTP para outro arquivo ou endereço.

Na prática, podemos usar o JavaScript para enviar dados para um arquivo PHP sem precisar recarregar a página. 

JavaScript
            ↓
            

            fetch()
            ↓
            salvar.php
            ↓
            Banco de dados

📝 Exemplo completo

HTML: 

<form id="formulario">

            <input type="text" name="andar">

            <input type="text" name="setor">

            <button type="submit">
                Salvar
            </button>

JavaScript: 

const formulario = document.querySelector('#formulario');
            

            formulario.addEventListener('submit', (event) => {

            
            event.preventDefault();

            const dados = new FormData(formulario);

            fetch('salvar.php', {

                method: 'POST',

                body: dados

            });
            

            });

📦 FormData

const dados = new FormData(formulario);

FormData pega os dados dos campos do formulário e cria uma estrutura que pode ser enviada para o servidor.

O mais importante é que os campos precisam possuir o atributo name. 

<input
            type="text"
            name="andar"
            

            >

O PHP poderá receber esse valor através de: 

$_POST['andar']

⏳ async, await e try/catch

Muitas operações em JavaScript não terminam imediatamente. Por exemplo, uma requisição fetch() pode precisar de algum tempo para chegar ao servidor e receber uma resposta.

Para trabalhar melhor com esse tipo de operação, usamos principalmente async e await.

⏳ O que significa assíncrono?

Uma operação assíncrona é uma operação que pode continuar acontecendo enquanto o restante da aplicação aguarda o resultado.

Um exemplo clássico é uma requisição para o PHP: 

JavaScript
            ↓
            

            "PHP, faça isso"
            ↓
            requisição
            ↓
            ⏳ aguardando resposta
            ↓
            PHP responde
            ↓
            JavaScript continua

⚡ async

Quando colocamos async antes de uma função, estamos indicando que aquela função trabalha de forma assíncrona e poderá utilizar await. 

async function salvar() {

            // código assíncrono
            

            }

Também podemos utilizar com Arrow Functions: 

const salvar = async () => {

            // código assíncrono
            

            };

⏸️ await

await significa, de forma simplificada: 

"Espere esta operação terminar
            

            antes de continuar esta função."

Exemplo: 

const resposta = await fetch('salvar.php');

O JavaScript aguarda o resultado do fetch() antes de passar para a próxima linha daquela função.

📦 await não funciona sozinho

Normalmente, await é utilizado dentro de uma função marcada com async. 

async function salvar() {

            const resposta = await fetch('salvar.php');
            

            }

🌐 fetch() com async/await

const salvar = async () => {

            const resposta = await fetch('salvar.php');

            const data = await resposta.json();

            console.log(data);
            

            };

Temos duas operações que precisam ser aguardadas: 

fetch()
            

            ↓
            resposta

            resposta.json()
            ↓
            data

🧠 O que acontece linha por linha?

const resposta = await fetch('salvar.php');

Envia a requisição para o PHP e aguarda a resposta. 

const data = await resposta.json();

Pega a resposta recebida e converte o JSON em um objeto JavaScript. 

console.log(data);

Agora podemos trabalhar com os dados recebidos.

🛡️ try

O try define um bloco de código que queremos tentar executar. 

try {

            // tente executar este código
            

            }

Se alguma operação dentro dele gerar um erro que possa ser tratado, podemos capturá-lo no catch.

🚨 catch

try {

            // código
            

            } catch (erro) {

            
            // tratamento do erro
            

            }

O parâmetro erro contém informações sobre o erro capturado. 

console.error(erro);

🔗 fetch() + try/catch

try {

            const resposta = await fetch('salvar.php');

            const data = await resposta.json();

            console.log(data);
            

            } catch (erro) {

            
            console.error('Erro na comunicação:', erro);
            

            }

Se houver um problema que faça a operação falhar, o código passa para o catch.

🧩 Desmontando o código

async (event) =>

A função do evento é assíncrona, permitindo utilizar await. 

event.preventDefault();

Impede o comportamento padrão do formulário. 

const dados = new FormData(formulario);

Pega os dados do formulário. 

const resposta = await fetch(...);

Envia os dados e aguarda a resposta do PHP. 

const data = await resposta.json();

Converte a resposta JSON em um objeto JavaScript. 

if (data.sucesso)

Verifica se o PHP informou que a operação foi bem-sucedida. 

catch (erro)

Trata problemas que ocorrerem durante a operação.

⚠️ Erro importante: HTTP não é automaticamente erro

Existe uma pegadinha importante com fetch(): uma resposta HTTP como 404 ou 500 não faz necessariamente o fetch() cair automaticamente no catch.

Por isso, podemos verificar: 

if (!resposta.ok) {

            throw new Error('Erro HTTP: ' + resposta.status);
            

            }

Assim, podemos transformar uma resposta HTTP problemática em um erro que será capturado pelo catch.

🛡️ Versão mais completa

            const resposta = await fetch('salvar.php', {

                method: 'POST',
                body: dados

            });

                throw new Error(
                    'Erro HTTP: ' + resposta.status
                );

            }

            const data = await resposta.json();

            if (data.sucesso) {

                console.log(data.mensagem);

            } else {

                console.log(data.mensagem);

            }
            

            } catch (erro) {

            
            console.error('Erro:', erro);
            

            }

            }

            // sempre executa
            

            }

Pode ser útil para ações como esconder um indicador de carregamento depois que uma operação terminou.

💾 Exemplo completo do salvar

Este é um exemplo bastante próximo do padrão utilizado em uma aplicação como o GatMan. 

const formulario = document.querySelector('#formulario');
            

            const botao = formulario.querySelector(
            'button[type="submit"]'
            );

            const mensagem = document.querySelector('#mensagem');

            formulario.addEventListener('submit', async (event) => {

            
            event.preventDefault();

            const dados = new FormData(formulario);

            botao.disabled = true;

            botao.textContent = 'Salvando...';

            try {

                const resposta = await fetch('salvar.php', {

                    method: 'POST',
                    body: dados

                });

                if (!resposta.ok) {

                    throw new Error(
                        'Erro HTTP: ' + resposta.status
                    );

                }

                const data = await resposta.json();

                mensagem.textContent = data.mensagem;

                if (data.sucesso) {

                    mensagem.classList.add('sucesso');

                    formulario.reset();

                } else {

                    mensagem.classList.add('erro');

                }

            } catch (erro) {

                console.error(erro);

                mensagem.textContent =
                    'Erro ao comunicar com o servidor.';

                mensagem.classList.add('erro');

            } finally {

                botao.disabled = false;

                botao.textContent = 'Salvar';

            }
            

            });

            ↓
            3. Pega os dados
            ↓
            4. Desabilita botão
            ↓
            5. Mostra "Salvando..."
            ↓
            6. fetch()
            ↓
            7. PHP processa
            ↓
            8. PHP retorna JSON
            ↓
            9. JavaScript lê JSON
            ↓
            10. Verifica data.sucesso
            ↓
            11. Mostra mensagem
            ↓
            12. Limpa formulário se deu certo
            ↓
            13. finally libera o botão

✅ Validação de formulários

Antes de enviar dados para o servidor, podemos verificar se os campos possuem valores válidos. 

if (nome.value.trim() === '') {

            mensagem.textContent = 'Informe o nome.';

            return;
            

            }

O trim() remove espaços no início e no final do texto.

Quando usar?

Use validação no JavaScript para melhorar a experiência do usuário e evitar requisições desnecessárias.

⚠️ Importante

A validação do JavaScript não substitui a validação do PHP. 

JavaScript
            

            ↓
            validação rápida para o usuário

            PHP
            ↓
            validação obrigatória de segurança

⏳ Loading

            botao.textContent = 'Salvando...';

botao.disabled = false;
            

            botao.textContent = 'Salvar';

try {

            // requisição
            

            } finally {

            
            botao.disabled = false;

            }

♻️ Funções reutilizáveis

Se o mesmo código aparece várias vezes, provavelmente devemos transformá-lo em uma função.

const mostrarSucesso = (texto) => {

⏱️ Debounce

Debounce é útil quando uma função não deve ser executada a cada alteração imediatamente.

Por exemplo, em uma caixa de pesquisa: 

let timer;
            

            campo.addEventListener('input', () => {

            
            clearTimeout(timer);

            timer = setTimeout(() => {

                pesquisar();

            }, 500);
            

            });

Nesse exemplo, a pesquisa só acontece depois que o usuário para de digitar por aproximadamente 500 milissegundos.
