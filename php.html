🐘 PHP

O PHP é responsável pela parte do sistema que roda no servidor. No GatMan, ele recebe informações do navegador, conversa com o banco de dados e devolve uma resposta para o JavaScript.

🧠 Fluxo básico

Navegador
                    ↓
                JavaScript
                    ↓
                PHP
                    ↓
                Banco de dados
                    ↓
                PHP
                    ↓
                JavaScript
                    ↓
                Navegador

💾 Guia rápido — Como fazer um "Salvar"

Para criar um PHP que recebe dados do formulário e salva no banco, podemos seguir esta sequência:

1️⃣ Iniciar o PHP

<?php

2️⃣ Informar que a resposta será JSON

header('Content-Type: application/json; charset=utf-8');

3️⃣ Carregar a conexão

require_once 'conexao.php';

4️⃣ Receber os dados

$nome = $_POST['nome'] ?? '';
                $idade = $_POST['idade'] ?? '';

5️⃣ Validar os campos

if (empty($nome) || empty($idade)) {

                    echo json_encode([
                        'sucesso' => false,
                        'mensagem' => 'Preencha os campos obrigatórios.'
                    ]);

                    exit;
                }

6️⃣ Criar o SQL

$sql = "INSERT INTO usuarios
                        (nome, idade)
                        VALUES (?, ?)";

7️⃣ Preparar

$stmt = $pdo->prepare($sql);

8️⃣ Executar

$stmt->execute([
                    $nome,
                    $idade
                ]);

9️⃣ Retornar sucesso

echo json_encode([
                    'sucesso' => true,
                    'mensagem' => 'Salvo com sucesso!'
                ]);

Como iniciar um arquivo PHP

<?php

                // código PHP aqui

                ?>

O que é?

<?php informa ao servidor que a partir daquele ponto começa um bloco de código PHP.

Em um arquivo que contém somente PHP, normalmente não é necessário fechar com ?>.

Exemplo

<?php

                echo "Olá!";

📦 Retornando JSON

header('Content-Type: application/json; charset=utf-8');

O que faz?

Informa ao navegador que a resposta enviada pelo PHP será um JSON codificado em UTF-8.

Por que usar?

Porque o JavaScript consegue receber essa resposta e transformá-la em um objeto para trabalhar com os dados.

Exemplo

echo json_encode([
                    'sucesso' => true,
                    'mensagem' => 'Salvo com sucesso!'
                ]);

O PHP envia algo parecido com: 

{
                    "sucesso": true,
                    "mensagem": "Salvo com sucesso!"
                }

🔌 Conectando ao banco

require_once 'conexao.php';

O que faz?

Carrega o arquivo responsável pela conexão com o banco de dados.

Por que usar require_once?

Ele inclui o arquivo necessário e evita que o mesmo arquivo seja incluído novamente caso já tenha sido carregado.

No GatMan

Depois de carregar conexao.php, temos acesso à variável de conexão, que no nosso caso é: 

$pdo

👤 Sessão

session_start();

O que faz?

Inicia ou recupera uma sessão existente.

A sessão permite guardar informações do usuário entre diferentes requisições.

Exemplo do GatMan

$_SESSION['usuario']

Podemos recuperar o usuário atualmente logado.

📝 Carregando o log

require_once 'log.php';

Inclui o arquivo responsável pelo sistema de registro de ações do GatMan.

O funcionamento específico dependerá do que existe dentro do arquivo log.php.

🛡️ TRY / CATCH

try {

                    // código que pode gerar erro

                } catch (PDOException $e) {

                    // tratamento do erro

                }

O que é?

O try tenta executar um determinado bloco de código.

Se ocorrer um erro relacionado ao PDO, o catch pode capturá-lo.

Por que usar?

Para evitar que um erro no banco simplesmente interrompa o processamento sem uma resposta adequada.

📥 Recebendo dados com POST

$andar = $_POST['andar'] ?? '';

O que está acontecendo?

O PHP está procurando um valor enviado pelo navegador chamado andar. 

$_POST
                ↓
                dados enviados pelo método POST

                ['andar']
                ↓
                campo chamado "andar"

E o ???

$_POST['andar'] ?? ''

Significa:

Se andar existir, use seu valor. Caso contrário, use uma string vazia.

Exemplo

$setor = $_POST['setor'] ?? '';
                $item = $_POST['item'] ?? '';
                $status = $_POST['status'] ?? '';

❓ Valores opcionais

$modelo = $_POST['modelo'] ?? null;

Aqui estamos fazendo praticamente a mesma coisa, mas usando null como valor padrão.

Isso é útil quando o campo pode ficar vazio. 

$modelo = $_POST['modelo'] ?? null;
                $observacoes = $_POST['observacoes'] ?? null;
                $data_manutencao = $_POST['data_manutencao'] ?? null;

🧠 Regra mental

?? '' 
                ↓
                se não existir → texto vazio

                ?? null
                ↓
                se não existir → NULL

👤 Recuperando o usuário

$usuario = $_SESSION['usuario'] ?? 'Desconhecido';

O PHP tenta encontrar o nome do usuário dentro da sessão.

Caso não encontre, utiliza: 

Desconhecido

✅ Validando os campos

if (
                    empty($andar) ||
                    empty($setor) ||
                    empty($item) ||
                    empty($status)
                ) {

                    echo json_encode([
                        'sucesso' => false,
                        'mensagem' => 'Preencha todos os campos obrigatórios.'
                    ]);

                    exit;
                }

O que faz?

Verifica se algum dos campos obrigatórios está vazio.

O que significa ||?

Significa OU. 

andar vazio
                OU
                setor vazio
                OU
                item vazio
                OU
                status vazio

Se qualquer uma dessas condições for verdadeira, o PHP retorna uma mensagem de erro.

Por que existe o exit?

exit;

Ele encerra imediatamente a execução do PHP.

💾 INSERT — salvando no banco

$sql = "INSERT INTO inspecao_seguranca
                        (andar, setor, item, status, modelo, observacoes, data_manutencao, usuario)
                        VALUES (?, ?, ?, ?, ?, ?, ?, ?)";

O que é?

INSERT INTO é utilizado para inserir um novo registro em uma tabela.

Estrutura

INSERT INTO tabela
                    (coluna1, coluna2, coluna3)

                VALUES
                    (?, ?, ?);

Primeiro informamos a tabela e as colunas. Depois informamos os valores que serão inseridos.

❓ Os ? do SQL

VALUES (?, ?, ?, ?, ?, ?, ?, ?)

Os ? são placeholders.

Eles representam os valores que serão enviados posteriormente.

Isso permite utilizar consultas preparadas com PDO, evitando colocar diretamente os valores enviados pelo usuário dentro do SQL.

Exemplo

$sql = "INSERT INTO tabela
                        (nome, idade)
                        VALUES (?, ?)";

Depois: 

$stmt->execute([
                    $nome,
                    $idade
                ]);

O primeiro valor vai para o primeiro ?, o segundo para o segundo, e assim por diante.

🛠️ prepare()

$stmt = $pdo->prepare($sql);

O que faz?

Prepara a consulta SQL para ser executada. 

$pdo
                ↓
                conexão com o banco

                prepare()
                ↓
                prepara o SQL

                $stmt
                ↓
                consulta preparada

▶️ execute()

$stmt->execute([
                    $andar,
                    $setor,
                    $item,
                    $status,
                    $modelo,
                    $observacoes,
                    $data_manutencao,
                    $usuario
                ]);

O que faz?

Executa a consulta preparada e envia os valores correspondentes aos ?.

🧠 A sequência

$sql
                ↓
                define o SQL

                $pdo->prepare($sql)
                ↓
                prepara

                $stmt->execute([...])
                ↓
                executa

✅ Retornando sucesso

echo json_encode([
                    'sucesso' => true,
                    'mensagem' => 'Inspeção de segurança salva com sucesso!'
                ]);

Depois de salvar o registro, o PHP envia uma resposta para o JavaScript.

O JavaScript poderá verificar: 

sucesso = true

e então mostrar uma mensagem para o usuário.

🚨 Tratando erros do banco

catch (PDOException $e) {

                    echo json_encode([
                        'sucesso' => false,
                        'mensagem' => 'Erro ao salvar a inspeção.',
                        'erro' => $e->getMessage()
                    ]);

                }

O que é PDOException?

É uma exceção relacionada ao PDO, utilizada para capturar erros relacionados à operação com o banco.

E o $e?

É o objeto que contém informações sobre o erro. 

$e->getMessage()

retorna a mensagem do erro.

⚠️ Atenção

Durante desenvolvimento, visualizar a mensagem do erro pode ser útil. Em produção, normalmente não devemos expor detalhes internos do banco diretamente para o usuário.

✏️ Editar dados — UPDATE

Para editar um registro existente no banco de dados, usamos o comando UPDATE.

No PHP, a lógica é muito parecida com o INSERT. A principal diferença é que agora precisamos informar qual registro será alterado.

🧠 Estrutura básica

UPDATE tabela
            SET coluna = ?
            WHERE id = ?;

1️⃣ Receber os dados

$id = $_POST['id'] ?? '';
            $status = $_POST['status'] ?? '';
            $observacoes = $_POST['observacoes'] ?? '';

O PHP recebe o id do registro que queremos alterar e os novos valores.

2️⃣ Criar o SQL

$sql = "UPDATE inspecao_seguranca
                    SET status = ?, observacoes = ?
                    WHERE id = ?";

3️⃣ Preparar

$stmt = $pdo->prepare($sql);

4️⃣ Executar

$stmt->execute([
                $status,
                $observacoes,
                $id
            ]);

⚠️ O WHERE é obrigatório na prática

UPDATE inspecao_seguranca
            SET status = 'Concluído';

Sem WHERE, o comando altera todos os registros.

Para editar somente um registro: 

UPDATE inspecao_seguranca
            SET status = 'Concluído'
            WHERE id = 15;

🗑️ Excluir dados — DELETE

Para excluir um registro do banco de dados, usamos o comando DELETE.

🧠 Estrutura básica

DELETE FROM tabela
            WHERE id = ?;

1️⃣ Receber o ID

$id = $_POST['id'] ?? '';

Normalmente, para excluir um registro específico, precisamos apenas do seu id.

2️⃣ Criar o SQL

$sql = "DELETE FROM inspecao_seguranca
                    WHERE id = ?";

3️⃣ Preparar

$stmt = $pdo->prepare($sql);

4️⃣ Executar

$stmt->execute([
                $id
            ]);

5️⃣ Retornar sucesso

echo json_encode([
                'sucesso' => true,
                'mensagem' => 'Registro excluído com sucesso!'
            ]);

⚠️ MUITO cuidado com o WHERE

Nunca faça isso sem ter certeza do que está fazendo: 

DELETE FROM inspecao_seguranca;

Sem WHERE, o comando pode excluir todos os registros da tabela.
