🎨 CSS — Introdução

CSS (Cascading Style Sheets) é utilizado para definir a aparência e o layout de uma página HTML.

Enquanto o HTML define a estrutura, o CSS define como essa estrutura será apresentada. 

HTML → estrutura
        CSS → aparência
        JavaScript → comportamento

🔗 Como inserir CSS

CSS externo

A forma mais comum é utilizar um arquivo separado: 

<link rel="stylesheet" href="style.css">

CSS interno

Também podemos colocar CSS dentro do próprio HTML: 

<style>
        h1 {
            color: blue;
        }
        </style>

CSS inline

Também é possível aplicar diretamente no elemento: 

<h1 style="color: blue;">
        Título
        </h1>

Em projetos maiores, normalmente é preferível utilizar arquivos CSS separados.

🎯 Seletores

Elemento

Seleciona todos os elementos daquele tipo: 

p {
        color: blue;
        }

Classe

Classes começam com .: 

.card {
        padding: 20px;
        }

ID

IDs começam com #: 

#menu {
        background: black;
        }

Vários seletores

h1, h2, h3 {
        font-family: Arial;
        }

Elemento dentro de outro

.card p {
        color: gray;
        }

Nesse exemplo, qualquer p dentro de .card será selecionado.

📦 Box Model

Todo elemento HTML pode ser entendido como uma caixa formada por: 


        ┌─────────────────────────┐
        │         margin          │
        │  ┌───────────────────┐  │
        │  │      border       │  │
        │  │  ┌─────────────┐  │  │
        │  │  │   padding   │  │  │
        │  │  │  ┌───────┐  │  │  │
        │  │  │  │content│  │  │  │
        │  │  │  └───────┘  │  │  │
        │  │  └─────────────┘  │  │
        │  └───────────────────┘  │
        └─────────────────────────┘

A ordem é: 

content
        padding
        border
        margin

↔️ Margin e Padding

Margin

Controla o espaço externo do elemento. 

.caixa {
        margin: 20px;
        }

Padding

Controla o espaço interno do elemento. 

.caixa {
        padding: 20px;
        }

Valores individuais

margin-top: 10px;
        margin-right: 20px;
        margin-bottom: 10px;
        margin-left: 20px;

Também podemos usar a forma abreviada: 

margin: 10px 20px;

Isso significa: 

10px → cima e baixo
        20px → esquerda e direita

🔲 Bordas

.caixa {
        border: 1px solid black;
        }

Podemos controlar cada propriedade separadamente: 

border-width: 1px;
        border-style: solid;
        border-color: black;
        border-radius: 10px;

📐 Display

A propriedade display define como um elemento participa do layout. 

display: block;
        display: inline;
        display: inline-block;
        display: flex;
        display: grid;
        display: none;

display: none remove o elemento da área visual.

📦 Flexbox

Flexbox é utilizado principalmente para organizar elementos em uma linha ou coluna. 

.container {
        display: flex;
        }

Direção

flex-direction: row;
        flex-direction: column;

Alinhamento horizontal

justify-content: center;

Outros valores comuns: 

flex-start
        flex-end
        center
        space-between
        space-around
        space-evenly

Alinhamento vertical

align-items: center;

Espaçamento

gap: 20px;

Exemplo completo

.container {
        display: flex;
        justify-content: center;
        align-items: center;
        gap: 20px;
        }

🔳 CSS Grid

Grid é utilizado para criar layouts baseados em linhas e colunas. 

.container {
        display: grid;
        grid-template-columns: repeat(3, 1fr);
        gap: 20px;
        }

Nesse exemplo, o container possui três colunas de tamanho proporcional.

Exemplo

.container {
        display: grid;
        grid-template-columns: 1fr 1fr 1fr;
        gap: 10px;
        }

📍 Position

A propriedade position controla como um elemento é posicionado. 

position: static;
        position: relative;
        position: absolute;
        position: fixed;
        position: sticky;

Relative

.caixa {

        }

Absolute

Fixed

        position: fixed;

        right: 20px;

🎭 Pseudo-classes

Pseudo-classes permitem aplicar estilos dependendo do estado de um elemento.

Hover

button:hover {
        background-color: black;
        }

Focus

input:focus {
        border-color: blue;
        }

Outros exemplos

:hover
        :focus
        :active
        :checked
        :disabled
        :first-child
        :last-child
        :nth-child()

✨ Pseudo-elementos

Pseudo-elementos permitem estilizar partes específicas de um elemento. 

::before
        ::first-line

Exemplo

.titulo::before {
        content: "★ ";
        }

📦 Overflow

Controla o que acontece quando o conteúdo ultrapassa o tamanho definido para o elemento. 

overflow: visible;
        overflow: hidden;
        overflow: scroll;
        overflow: auto;

Um uso comum é permitir rolagem apenas quando necessário: 

.container {
        overflow: auto;
        }

🎞️ Transições

transition permite criar mudanças suaves entre estados. 

button {
        background-color: blue;
        transition: 0.3s;
        }

        button:hover {
        background-color: black;
        }

📱 Responsividade

Media Queries permitem alterar o CSS dependendo do tamanho da tela. 

@media (max-width: 768px) {
        .container {
            flex-direction: column;
        }
        }

Exemplo de tamanhos frequentemente utilizados: 

768px  → tablets
        480px  → celulares

Esses valores são apenas referências. O breakpoint ideal depende do layout do projeto.

🎨 Variáveis CSS

Variáveis permitem armazenar valores que podem ser reutilizados no CSS. 

:root {
        --cor-principal: #3498db;
        --cor-texto: #333;
        --espacamento: 20px;
        }

        .card {
        color: var(--cor-texto);
        padding: var(--espacamento);
        background-color: var(--cor-principal);
        }

📦 Box-sizing

box-sizing controla como o tamanho total de um elemento é calculado.

Uma configuração muito comum é: 

* {
        box-sizing: border-box;
        }

Com border-box, o padding e a border ficam incluídos no width e height definidos.

🧩 Combinando seletores

Um exemplo utilizando várias propriedades juntas: 

<div class="card">
        <h2>React</h2>
        <p>Aprendendo React.</p>
        <button>Ver tutorial</button>
        </div>
.card {
        width: 300px;
        padding: 20px;
        border: 1px solid #ccc;
        border-radius: 10px;
        background-color: white;
        text-align: center;
        }

        .card button {
        padding: 10px 20px;
        border: none;
        border-radius: 5px;
        cursor: pointer;
        }

        .card button:hover {
        opacity: 0.8;
        }
