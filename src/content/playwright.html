🎭 O que é Playwright?

Playwright é uma ferramenta de automação de testes que controla um navegador e verifica se uma aplicação funciona como esperado.

Com ele, podemos simular ações de um usuário:

  • Abrir páginas;
  • Clicar em links e botões;
  • Preencher formulários;
  • Verificar títulos, URLs e elementos visíveis;
  • Encontrar problemas de navegação;
  • Executar os mesmos testes automaticamente sempre que necessário.

Teste E2E (End-to-End): testa um fluxo da aplicação do ponto de vista do usuário, desde uma ação inicial até o resultado esperado.

Exemplo no How2: abrir a Home, clicar em CSS e verificar se a página CSS foi aberta.

📦 Instalar o Playwright

Execute os comandos no terminal, dentro da pasta do projeto.

npm init playwright@latest

Durante a configuração, escolha:

  • JavaScript;
  • tests como pasta dos testes;
  • Não adicionar workflow do GitHub Actions por enquanto;
  • Instalar os navegadores.

A instalação cria arquivos como:

howto/
            ├── tests/
            │   └── example.spec.js
            ├── playwright.config.js
            ├── package.json
            └── ...

Atenção: se o projeto já tem Playwright instalado, não é necessário repetir a instalação.

🚀 Executar os primeiros testes

Para executar os testes existentes, entre na pasta do projeto e rode:

npx playwright test

Exemplo de resultado:

6 passed (4.2s)

Isso significa que seis testes passaram. Se algum falhar, o Playwright mostra qual teste falhou e apresenta detalhes para investigar.

Para abrir o relatório HTML da última execução:

npx playwright show-report

O relatório ajuda a identificar os testes executados, seus resultados e detalhes das falhas.

🧩 Estrutura de um teste

import { test, expect } from '@playwright/test';

            test('has title', async ({ page }) => {
                await page.goto('https://playwright.dev/');

                await expect(page).toHaveTitle(/Playwright/);
            });
  • test: define um teste;
  • expect: verifica se o resultado corresponde ao esperado;
  • page: representa uma página do navegador controlada pelo Playwright;
  • page.goto(): abre uma URL;
  • await: espera uma operação assíncrona terminar antes de continuar;
  • toHaveTitle(): verifica o título da página.

O nome do teste, como has title, é uma descrição para facilitar a leitura dos resultados.

📝 Criar um teste próprio

Crie um arquivo com a extensão .spec.js dentro da pasta tests.

Exemplo de organização:

tests/
            ├── example.spec.js
            └── how2.spec.js

O arquivo how2.spec.js será usado para os testes automatizados do How2.

Exemplo: abrir a Home localmente, clicar na categoria CSS e verificar se a URL mudou para a página esperada.

import { test, expect } from '@playwright/test';

            test('abrir CSS pela Home', async ({ page }) => {
                await page.goto('http://localhost:5173/howto/');

                await page.getByRole('link', { name: 'CSS' }).click();

                await expect(page).toHaveURL(/css/);
            });

Importante: este exemplo pressupõe que o servidor local esteja acessível nesse endereço e que exista um link cujo nome acessível seja CSS. Se o teste falhar, confira o endereço e o nome real do link antes de alterar a aplicação.

🔎 Encontrar elementos — Locators

Um locator é uma forma de localizar um elemento na página para interagir com ele ou verificar seu estado.

1. getByRole() — pelo papel e nome acessível

É uma das opções preferidas para links, botões, campos e outros elementos interativos.

// Link chamado CSS
            page.getByRole('link', { name: 'CSS' });

            // Botão chamado Salvar
            page.getByRole('button', { name: 'Salvar' });

            // Título chamado Introdução
            page.getByRole('heading', { name: 'Introdução' });

            // Campo de texto
            page.getByRole('textbox', { name: 'E-mail' });

            // Checkbox
            page.getByRole('checkbox', { name: 'Aceito os termos' });

            // Radio button
            page.getByRole('radio', { name: 'Sim' });

            // Lista
            page.getByRole('list');

            // Item de lista
            page.getByRole('listitem');

Também é possível procurar um título de nível específico:

page.getByRole('heading', {
                name: 'Introdução',
                level: 2
            });

2. getByText() — pelo texto visível

// Texto que contém a expressão
            page.getByText('Tutorial');

            // Texto exato
            page.getByText('Tutorial', { exact: true });

            // Texto que corresponde a uma expressão regular
            page.getByText(/tutorial/i);

Use principalmente para parágrafos, mensagens e textos que não sejam elementos interativos.

3. getByLabel() — pelo rótulo de um campo

page.getByLabel('Nome');
            page.getByLabel('E-mail');
            page.getByLabel('Palavra-passe');

É útil quando o campo possui um label associado corretamente.

4. getByPlaceholder() — pelo texto de exemplo

page.getByPlaceholder('Digite seu nome');
            page.getByPlaceholder('nome@exemplo.com');

5. getByAltText() — pelo texto alternativo de uma imagem

page.getByAltText('Logotipo do How2');

6. getByTitle() — pelo atributo title

page.getByTitle('Voltar para a Home');

7. getByTestId() — por um identificador de teste

Útil quando o elemento não possui um nome acessível estável ou quando existe um identificador definido especificamente para os testes.

// HTML:
            <button data-testid="salvar">Guardar</button>

            // Playwright:
            page.getByTestId('salvar');

8. locator() — por seletor CSS

// Pelo ID
            page.locator('#menu');

            // Pela classe
            page.locator('.categoria');

            // Pelo elemento HTML
            page.locator('button');

            // Pelo atributo
            page.locator('[href="/howto/css"]');

            // Por um campo de tipo email
            page.locator('input[type="email"]');

Prefira locators orientados ao usuário, como getByRole e getByLabel, quando forem adequados. Use seletores CSS quando precisar identificar algo que os outros métodos não localizam bem.

9. Combinar e filtrar locators

// Procurar um link dentro do menu
            page.locator('nav').getByRole('link', { name: 'CSS' });

            // Procurar um elemento que contém determinado texto
            page.getByRole('listitem').filter({
                hasText: 'CSS'
            });

            // Procurar um botão dentro de um cartão
            page.locator('.categoria').getByRole('link');

Se existirem vários elementos semelhantes, use first(), last() ou nth() para escolher um específico. Lembre-se de que nth() começa em zero.

page.getByRole('link').first();
            page.getByRole('link').last();
            page.getByRole('link').nth(1);

🖱️ Executar ações nos elementos

1. Clicar

await page.getByRole('button', { name: 'Salvar' }).click();

            await page.getByRole('link', { name: 'CSS' }).click();

2. Duplo clique

await page.getByText('Editar', { exact: true }).dblclick();

3. Preencher um campo

fill() preenche o campo com o valor indicado, substituindo o conteúdo anterior.

await page.getByLabel('Nome').fill('Wagner');

            await page.getByLabel('E-mail').fill('teste@exemplo.com');

4. Limpar um campo

await page.getByLabel('Nome').clear();

5. Digitar caractere a caractere

await page.getByLabel('Nome').pressSequentially('Wagner');

Use pressSequentially() quando precisar simular a digitação de caracteres individualmente, por exemplo, para testar comportamentos que reagem a cada tecla.

6. Pressionar teclas

// Enter num campo
            await page.getByLabel('Pesquisar').press('Enter');

            // Escape
            await page.keyboard.press('Escape');

            // Ctrl+A dentro de um campo
            await page.getByLabel('Nome').press('Control+A');

            // Tecla Tab
            await page.keyboard.press('Tab');

7. Marcar e desmarcar checkbox

await page.getByRole('checkbox', {
                name: 'Aceito os termos'
            }).check();

            await page.getByRole('checkbox', {
                name: 'Aceito os termos'
            }).uncheck();

8. Selecionar uma opção de radio

await page.getByRole('radio', {
                name: 'Sim'
            }).check();

9. Escolher uma opção de select

// Pelo valor da opção
            await page.getByLabel('Categoria').selectOption('css');

            // Pelo texto visível da opção
            await page.getByLabel('Categoria').selectOption({
                label: 'CSS'
            });

10. Passar o rato sobre um elemento

await page.getByRole('button', {
                name: 'Mais opções'
            }).hover();

11. Focar e retirar o foco

await page.getByLabel('Nome').focus();

            await page.getByLabel('Nome').blur();

12. Enviar um formulário

await page.getByRole('button', {
                name: 'Enviar'
            }).click();

Também pode pressionar Enter num campo, se esse for o comportamento esperado do formulário.

13. Fazer scroll até um elemento

await page.getByRole('heading', {
                name: 'Resumo'
            }).scrollIntoViewIfNeeded();

14. Arrastar e soltar

await page.locator('#origem').dragTo(
                page.locator('#destino')
            );

15. Navegar pelo histórico

await page.goBack();

            await page.goForward();

            await page.reload();

O Playwright espera automaticamente por várias condições de interação, como o elemento estar visível e habilitado antes de clicar. Evite adicionar esperas fixas sem necessidade.

✅ Verificar resultados — expect()

As verificações confirmam se a aplicação apresentou o resultado esperado. Se uma verificação falhar, o teste falha.

1. Verificar a URL

await expect(page).toHaveURL(/css/);

            await expect(page).toHaveURL(
                'http://localhost:5173/howto/'
            );

2. Verificar o título do documento

await expect(page).toHaveTitle(/How2/);

3. Verificar se um elemento está visível

await expect(
                page.getByRole('heading', { name: 'CSS' })
            ).toBeVisible();

4. Verificar se um elemento está oculto

await expect(
                page.getByText('Mensagem de erro')
            ).toBeHidden();

5. Verificar se um elemento existe no DOM

await expect(
                page.getByTestId('resultado')
            ).toHaveCount(1);

toHaveCount(0) verifica que não há elementos correspondentes. Diferentemente de toBeHidden(), isso também passa quando o elemento não existe no DOM.

6. Verificar o texto

await expect(
                page.getByRole('heading', { name: 'CSS' })
            ).toHaveText('CSS');

            await expect(
                page.locator('.mensagem')
            ).toContainText('Salvo');

toHaveText() verifica o texto esperado; toContainText() verifica se o texto contém a expressão indicada.

7. Verificar o valor de um campo

await expect(
                page.getByLabel('Nome')
            ).toHaveValue('Wagner');

8. Verificar se está habilitado ou desabilitado

await expect(
                page.getByRole('button', { name: 'Salvar' })
            ).toBeEnabled();

            await expect(
                page.getByRole('button', { name: 'Salvar' })
            ).toBeDisabled();

9. Verificar checkbox marcado

await expect(
                page.getByRole('checkbox', { name: 'Aceito os termos' })
            ).toBeChecked();

Para confirmar que está desmarcado:

await expect(
                page.getByRole('checkbox', { name: 'Aceito os termos' })
            ).not.toBeChecked();

10. Verificar atributos

await expect(
                page.getByRole('link', { name: 'CSS' })
            ).toHaveAttribute('href', '/howto/css');

11. Verificar classes CSS

await expect(
                page.locator('.categoria')
            ).toHaveClass(/categoria/);

12. Verificar quantidade de elementos

// Existem sete links
            await expect(page.getByRole('link')).toHaveCount(7);

Use a quantidade que realmente corresponde à página testada. O exemplo acima é ilustrativo.

13. Verificar se uma imagem está visível

await expect(
                page.getByRole('img', { name: 'Logotipo do How2' })
            ).toBeVisible();

14. Verificar se um texto não aparece

await expect(
                page.getByText('Erro ao salvar')
            ).not.toBeVisible();

Use essa verificação quando o resultado esperado for que a mensagem não esteja visível. Se precisar confirmar que o elemento não existe no DOM, prefira toHaveCount(0).

📋 Trabalhar com listas e vários elementos

1. Selecionar o primeiro, último ou um item específico

const links = page.getByRole('link');

            await links.first().click();
            await links.last().click();
            await links.nth(2).click();

Os exemplos são alternativas: não execute os três cliques em sequência sem considerar o que cada navegação provoca.

2. Verificar uma lista inteira

await expect(
                page.getByRole('link')
            ).toHaveText([
                'HTML',
                'CSS',
                'JavaScript'
            ]);

A lista de textos e a quantidade de links devem corresponder ao conteúdo real da página.

3. Percorrer os elementos encontrados

const links = await page.getByRole('link').all();

            for (const link of links) {
                console.log(await link.innerText());
            }

all() recolhe os elementos encontrados naquele momento e não espera que uma lista dinâmica termine de carregar. Para verificar textos, prefira expect(locator).toHaveText() quando possível.

⏳ Esperas e carregamento

1. Esperar por um elemento aparecer

await expect(
                page.getByText('Carregado')
            ).toBeVisible();

As asserções do Playwright tentam novamente até o resultado ser alcançado ou o tempo limite terminar.

2. Esperar por uma URL

await expect(page).toHaveURL(/css/);

3. Esperar por uma resposta de rede específica

const respostaPromise = page.waitForResponse(
                response => response.url().includes('/api/dados')
            );

            await page.getByRole('button', { name: 'Carregar' }).click();

            const resposta = await respostaPromise;

            expect(resposta.ok()).toBeTruthy();

Registre a espera antes da ação que provoca a requisição, para não perder uma resposta rápida.

4. Espera fixa — usar apenas quando necessário

await page.waitForTimeout(1000);

Isso espera um segundo. Não é a forma preferida de sincronizar testes, pois pode deixar o teste lento ou instável. Prefira esperar pelo elemento, URL ou evento esperado.

💬 Diálogos, abas e downloads

1. Lidar com alert(), confirm() e prompt()

page.on('dialog', async dialog => {
                console.log(dialog.message());
                await dialog.accept();
            });

Registre o listener antes de executar a ação que abre o diálogo. O handler precisa aceitar ou dispensar o diálogo.

2. Abrir uma nova aba ou página

const paginaPromise = page.context().waitForEvent('page');

            await page.getByRole('link', { name: 'Abrir relatório' }).click();

            const novaPagina = await paginaPromise;

            await expect(novaPagina).toHaveURL(/relatorio/);

3. Verificar um download

const downloadPromise = page.waitForEvent('download');

            await page.getByRole('button', { name: 'Baixar' }).click();

            const download = await downloadPromise;

            console.log(download.suggestedFilename());

🛠️ Descobrir como localizar um elemento

Se não souber qual locator utilizar, o Playwright oferece o Codegen, que observa as suas ações e sugere código.

npx playwright codegen http://localhost:5173/howto/

Na janela aberta, navegue pela aplicação, clique nos elementos e observe o código sugerido. Use-o como ponto de partida e revise os locators gerados antes de guardar o teste.

O Codegen pode sugerir seletores mais específicos do que o necessário. Prefira um locator simples, legível e estável sempre que possível.

🧪 Exemplo completo — testar a navegação para CSS

import { test, expect } from '@playwright/test';

            test('abrir CSS pela Home', async ({ page }) => {
                await page.goto('http://localhost:5173/howto/');

                const linkCSS = page.getByRole('link', {
                    name: 'CSS'
                });

                await expect(linkCSS).toBeVisible();

                await linkCSS.click();

                await expect(page).toHaveURL(/css/);

                await expect(
                    page.getByRole('heading', { name: /CSS/i }).first()
                ).toBeVisible();
            });

Este teste verifica três coisas:

  1. O link CSS está visível na Home;
  2. O clique navega para uma URL que contém CSS;
  3. Um título correspondente a CSS está visível na página de destino.

Adapte o nome do link, o título e o endereço à aplicação real. O teste deve verificar o comportamento pretendido, não apenas fazer o código passar.

⚙️ Executar testes específicos

Executar todos os testes:

npx playwright test

Executar apenas um arquivo:

npx playwright test how2.spec.js

Executar somente no Chromium:

npx playwright test --project=chromium

Executar em modo interativo:

npx playwright test --ui

Executar em modo de depuração:

npx playwright test --debug

🐞 Investigar testes que falham

Quando um teste falhar:

  1. Identifique o nome do teste que falhou;
  2. Leia a mensagem de erro;
  3. Confira a URL, o seletor e o resultado esperado;
  4. Reproduza o problema manualmente, se necessário;
  5. Determine se o problema está no teste ou na aplicação;
  6. Corrija a causa e execute novamente.

Um teste que falha não prova automaticamente que existe um bug. O próprio teste pode estar incorreto ou desatualizado.

Regra de QA: não altere a aplicação apenas para fazer o teste passar. Primeiro descubra se o comportamento esperado está correto.

🏠 Playwright aplicado ao How2

O How2 é o projeto de prática dos testes automatizados. Podemos transformar os testes manuais em verificações repetíveis.

  • Home: categorias e links;
  • Navegação: menus e links internos;
  • Rotas: abrir páginas diretamente e usar Voltar/Avançar;
  • Responsividade: verificar elementos em telas menores;
  • Recursos: investigar erros de carregamento;
  • Regressão: repetir testes depois de alterações no código.

Comece com poucos testes, simples e confiáveis. Depois acrescente casos conforme surgirem necessidades reais.

🎯 Resumo para consultar rapidamente

// 1. Importar
            import { test, expect } from '@playwright/test';

            // 2. Criar teste
            test('nome do teste', async ({ page }) => {

                // 3. Abrir página
                await page.goto('http://localhost:5173/howto/');

                // 4. Executar ação
                await page.getByRole('link', { name: 'CSS' }).click();

                // 5. Verificar resultado
                await expect(page).toHaveURL(/css/);
            });

Comando principal:

npx playwright test

Relatório:

npx playwright show-report

Ideia central: preparar a situação → executar uma ação → verificar o resultado esperado.
