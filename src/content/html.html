🌐 HTML — Introdução

HTML (HyperText Markup Language) é a linguagem utilizada para estruturar o conteúdo de uma página web.

HTML define o que existe na página. O CSS define como esse conteúdo aparece. O JavaScript adiciona comportamento e interatividade. 

HTML → estrutura
            

            CSS → aparência
            JavaScript → comportamento

📄 Estrutura básica

Uma página HTML normalmente começa com esta estrutura: 

<!DOCTYPE html>
            

            

            
            
            Minha página
            

            

            
            <h1>Olá!</h1>

O <head> contém informações sobre a página. O <body> contém o conteúdo exibido na página.

📝 Títulos e parágrafos

Os títulos vão de h1 até h6: 


                <h1>Título principal</h1>
                    <h2>Subtítulo</h2>
                        <h3>Título menor</h3>

Para textos normais usamos p: 

<p>Este é um parágrafo.</p>

🔗 Links

O elemento <a> cria links: 

<a href="https://google.com">
            Google

Para abrir o link em uma nova aba: 

<a href="https://google.com" target="_blank">
            Google

🖼️ Imagens

O elemento <img> exibe uma imagem: 

<img src="imagem.jpg" alt="Descrição da imagem">

src indica o caminho da imagem e alt fornece uma descrição.

📋 Listas

Lista não ordenada

<ul>
            <li>React</li>
            <li>PHP</li>
            <li>CSS</li>

Lista ordenada

<ol>
            <li>Primeiro</li>
            <li>Segundo</li>
            <li>Terceiro</li>

📦 Div, Span, Class e ID

div

O div é um elemento genérico utilizado para agrupar outros elementos. 

<div>
            <h2>React</h2>
            <p>Tutorial de React.</p>

span

O span é utilizado normalmente para envolver uma pequena parte de um texto ou conteúdo. 

<p>
            Aprendendo <span>HTML</span>.

class

O atributo class identifica elementos que podem compartilhar o mesmo estilo ou comportamento. 

<div class="card">
            Conteúdo

id

O id identifica um elemento específico. 

<section id="react">
            Conteúdo

🧱 Elementos semânticos

Elementos semânticos ajudam a representar a função de cada parte da página. 

<header>
            Cabeçalho

📊 Tabelas

Uma tabela básica utiliza table, tr, th e td. 

<table>

            <tr>
                <th>Nome</th>
                <th>Idade</th>
            </tr>

            <tr>
                <td>João</td>
                <td>30</td>
            </tr>

📝 Formulários

Formulários são utilizados para receber informações do usuário. 

<form>

            <label>Nome:</label>
            <input type="text">

            <label>Email:</label>
            <input type="email">

            <button type="submit">
                Enviar
            </button>

⌨️ Inputs

O elemento input possui diversos tipos: 

<input type="text">

Placeholder

<input
            type="text"
            placeholder="Digite seu nome"
            

            >

🔘 Botões

Um botão simples: 

<button>
            Clique aqui

Dentro de um formulário, podemos especificar sua função: 

<button type="submit">
            Enviar

✍️ Formatação de texto

<strong>Texto importante</strong>
            

            Texto enfatizado

            Texto destacado

<br> cria uma quebra de linha e <hr> cria uma separação temática.

⚛️ HTML no React

No React utilizamos uma sintaxe muito parecida com HTML, chamada JSX. 

function App() {
            return (
                <div className="card">
                    <h1>Olá!</h1>
                    <p>Minha aplicação React.</p>
                </div>
            )
            

            }

Uma diferença importante é que utilizamos className em vez de class.
